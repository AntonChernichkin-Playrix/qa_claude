# Пример состава декомпозиции: «IDL. Проверка по ТЗ Remastered»

Реальная декомпозиция из Asana (`1217364044415843`), 45 подзадач. Ниже — 42: блоки про баунс кнопок, проверку после мерджа в мастер и чек-лист на регрессию в состав декомпозиции больше не входят, поэтому из примера убраны. Нумерация оставлена как в Asana, отсюда пропуски.

Пример показывает состав и нарезку, но **устарел в двух местах**: визуал в нём размазан по блокам HUD, окон и иконки — сейчас он собирается в один блок; вложенных подзадач «Написание чек-листа» больше нет. Актуальные правила — в [SKILL.md](../SKILL.md) и [template-blocks.md](template-blocks.md).

**Здесь только то, что переносится на любую фичу: состав блоков, их названия, порядок и решения об укрупнении/дроблении.** Проверки айдлера не приводятся: механика у каждой фичи своя, содержимое блоков копировать нельзя — его выводят из ТЗ. Формат тела задачи — в [format.md](format.md), состав обязательных блоков — в [template-blocks.md](template-blocks.md).

## Что перенять из этого состава

| Наблюдение | Вывод для новой фичи |
|---|---|
| 13 блоков из 45 — механика фичи, остальные 32 пришли из шаблона | Основная работа по ТЗ — середина списка; каркас берётся готовым |
| Один раздел ТЗ «Логика завершения» дал три блока (20, 21, 22) | Дробить по условиям входа, а не по разделам ТЗ |
| Четыре окна фичи собраны в один блок 25 | Однотипное, проверяемое одним прогоном, — объединять |
| «Окно дороги наград» вынесено отдельно (19) | Своя механика — расчёт и выдача наград по этапам, а не сложный арт. Только это и оправдывает отдельный блок для окна |
| Из «Персонажей» выделены механика (10) и система подсказок мержа (11) | Самостоятельная подсистема со своим UI — свой блок |
| Пометка `(доработка)` у блоков 20–22, 28, 29 | Так помечают блоки про изменения относительно предыдущей версии фичи |
| Блоков про просмотры здесь нет | Так и надо: задачи на просмотры в состав декомпозиции не входят |
| Визуал размазан по блокам HUD, окон и иконки | Так больше не делать: весь визуал — один блок «Проверка графики и визуала фичи» |

Правила дробления и укрупнения целиком — в [SKILL.md](../SKILL.md), раздел «Как резать ТЗ на блоки».
